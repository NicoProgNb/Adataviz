# ADATAVIZ

## Présentation
- main.js : Contenant le programme principal
- util.js : Contenant les fonctions réutilisable et à tester
- utils.test.js : Pas eu d'occasion de test (à améliorer)

## Utilisation
``ETAPE 1 - Télecharger``

Cloner le dépot git :
- Dans le terminal, se déplacer dans l'endroit souhaité (cd) pour cloner le dossier (git clone)
- Lien HTML : git clone https://github.com/NicoProgNb/Adataviz.git
        ou
- Lien SSH : git clone git@github.com:NicoProgNb/Adataviz.git

``ETAPE 2 - Executer``

- Ouvrir index.html dans le navigateur (ou en live serveur sur VsCode)

## Commentaire
La récupération de donnée via fetch, puis la notion de parser avec .json fonctionne via la notion de `promesse`.
Cette partie nouvelle a été intéressante et, je pense, plutôt bien comprise.
